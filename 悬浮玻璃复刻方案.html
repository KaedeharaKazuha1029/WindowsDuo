Surface Pro 无硬件复刻 iPhone Duo「悬浮玻璃」

Windows 二合一设备 + 内置姿态传感器 + PyQt6/OpenGL · 实现说明 · 2026-09-21
Surface Pro / Windows 二合一 无需 ESP32 无需 MPU6050 Windows Inclinometer Python + PyQt6

0. 结论先行

Surface Pro 不需要外接硬件。Windows Sensor Platform 的 Inclinometer 会直接提供设备当前的绝对姿态， 程序将其映射为开合角，再驱动全屏 OpenGL 玻璃层。默认约定为：合上 -90°，打开 0°。 需要 ESP32 + MPU6050 外部传感器方案，请访问原始仓库：KaedeharaKazuha1029/WindowsDuo。

1. 要复刻的效果到底是什么

根据公开评测与分析，iPhone Duo 的开合动画核心是三层叠加：

  • 物理映射层：铰链传感器实时回传角度，动画严格跟随手指开合节奏，毫秒级同步；
  • 磨砂玻璃中转层：切换内容不是硬切，而是经过一层"半透明磨砂玻璃"—— 模糊半径和透明度随折叠角度动态调整（合得越多 → 越模糊、越"虚"）；
  • 虚实渐变：旧内容渐隐入玻璃、新内容由虚到实渐现，方向与开合方向一致。

在 Surface Pro 这类 Windows 二合一设备上，这套效果的映射是：

合盖过程中：角度从 0° 向 -90° 变化，玻璃浓度增加； 打开过程中：角度从 -90° 回到 0°，画面恢复清晰。角度来自绝对姿态，不是启动后的累计变化量。

3. 角度测量：Surface Pro 内置传感器

3.1 原理

Windows Sensor Platform 的 Inclinometer 直接提供设备相对于重力方向的绝对姿态。 程序读取 pitch（必要时可改用 roll），不依赖启动时的零点，也不把陀螺仪积分变化量当成开合角。

// 互补滤波（推荐，无需卡尔曼）
sensor_pitch = inclinometer.get_current_reading().pitch_degrees;
angle = map(sensor_pitch, inclinometer_closed, inclinometer_open,
            angle_closed, angle_open);                 // 绝对两点映射
angle = ema(angle, angle_target, inclinometer_smoothing);
  • 不需要 ESP32、MPU6050、USB 线或串口；
  • Inclinometer 输出的是绝对姿态，避免纯陀螺仪积分漂移；
  • 陀螺仪只显示实时角速度，便于诊断，不参与绝对角度累计。

3.2 两点校准

姿态操作写入参数
完全合盖读取 Inclinometer 的 pitch 并写入 inclinometer_closed项目角度 = -90°
完全打开读取 pitch 并写入 inclinometer_open项目角度 = 0°

当前默认约定为 pitch=90° → -90°（合上），pitch=0° → 0°（打开）。不同机型应实测两个端点后修改配置。

3.3 没有可用内置传感器时

Surface Pro 版本不需要 ESP32、ESP8266、MPU6050 或串口。本仓库只维护 Windows 内置姿态传感器版本；需要外部传感器方案，请访问 原始仓库。

4. Windows 端实现（关键）

4.1 系统级 Acrylic 的局限，先说清楚

Windows 的 SetWindowCompositionAttribute(ACCENT_ENABLE_ACRYLICBLURBEHIND) 能给窗口加系统毛玻璃， 但模糊半径是系统固定的，不可调——只能调 tint 颜色的透明度。所以"blur 随角度变化"必须自己渲染。 系统 Acrylic 只适合做兜底/省电模式。

4.2 推荐方案：截图 + GLSL Overlay（效果最接近 Duo）

1
截屏一次：mss 抓取当前桌面 → 上传为 OpenGL 纹理。
2
生成 mip 纹理：OpenGL 为桌面纹理生成 mipmap，着色器按空间间隙选择采样 LOD，并进行 Vogel 盘采样。
3
全屏无边框窗口：PyQt6，FramelessWindowHint + WindowStaysOnTopHint， 按绝对角度 θ 计算玻璃平面与界面的逆投影，再叠加空间模糊和变暗 → "由实入虚"。
4
角度平滑与缓动：Inclinometer 绝对角度先过 EMA 平滑，再进玻璃参数的缓动（目标值插值）。 这样不会把启动后的累计变化量误当成开合角。
5
联动彩蛋：θ < 15° 时调用锁屏（LockWorkStation()）或触发屏保， 复刻"合盖即休眠"且不与系统电源行为打架。

4.3 兜底方案（省事版）

方案做法效果
B. 系统 Acrylic 遮罩全屏透明窗 + ACCENT_ACRYLIC，只调 tint alpha有玻璃感但模糊深度不可变，打折
C. 动态壁纸联动θ 分段切换 原图/模糊图 壁纸最简单但只有"档位感"，不跟手

建议直接做 A，B 作为降级开关（笔记本低电量/游戏时）。

6. 必须处理的坑

  • 系统"合盖=睡眠"：演示时把电源计划里"合上盖时"改为"不采取操作"： powercfg /setacvalueindex SCHEME_CURRENT SUB_BUTTONS LIDACTION 0
  • 截屏刷新：Overlay 显示的是"玻璃后面的世界"，桌面内容变化时需低频（如 500ms）重截重模糊， 或仅在 θ 进入过渡区间时刷新；否则模糊层背后是旧画面，会穿帮。
  • 穿帮窗（自己程序的窗口）：Overlay 置顶后，模糊层应排除自身窗口； 蒙版用桌面合成结果而非分层截图。
  • 传感器端点：如果合盖/全开时的 pitch 不是默认 90°/0°，修改 win/config.json 的两个端点。
  • 硬件依赖：Surface Pro 路径不需要 USB 传感器、串口、走线或外接模块。
  • 多显示器：Overlay 只覆盖主屏即可（笔记本场景）。
